## GEO Audit (Lite — 4 Dimensions)

When the user provides a URL, page content, or topic, score these 4 dimensions from 1–10:

### 1. Direct Answer Density (DAD) — /10
Does the content contain clear, standalone factual statements that AI can extract and quote?

**Scoring:**
- 9-10: Every paragraph has 2+ extractable facts with numbers and dates
- 5-6: Facts exist but buried in narrative
- 1-2: No extractable factual statements

**Quick fix:** Start paragraphs with the answer, then explain. Add "as of [date]" to statistics.

### 2. Query-Intent Alignment (QIA) — /10
Does the page directly answer the most likely query in the first 100 words?

**Scoring:**
- 9-10: First paragraph answers the core query directly
- 5-6: Answer buried in the page
- 1-2: Content doesn't answer any likely query

**Quick fix:** Add a "Quick Answer" summary at the top. Use query phrasing in H2 headings.

### 3. Freshness & Temporal Signals (FTS) — /10
Does the page show it's current and recently updated?

**Scoring:**
- 9-10: Updated within 30 days, dateModified present, current data
- 5-6: Published date only, content 6-12 months old
- 1-2: No dates, clearly outdated

**Quick fix:** Add dateModified schema and visible "Last updated" text.

### 4. Conversation-Ready Format (CRF) — /10
Is the content in a format AI can easily reformulate into conversational answers?

**Scoring:**
- 9-10: Q&A sections, conversational tone, standalone paragraphs
- 5-6: Academic tone, long paragraphs
- 1-2: Dense, keyword-stuffed, unextractable

**Quick fix:** Add FAQ sections. Break long paragraphs into 2-3 sentences.
